How the pipeline works

    Tech stack

    Models and data: Python 3.11, pandas, NumPy, scikit-learn, imbalanced-learn (SMOTE), XGBoost, LightGBM, TensorFlow/Keras, SHAP, matplotlib, seaborn, joblib, run in Jupyter Notebook.

    This website: one HTML file with plain JavaScript and Chart.js. Added datasets are kept in your browser’s local storage, so they stay on your device.

    How to explain this project

    The first answer updates with the dataset you select.

    Add another dataset

    Train the same models on a new dataset (for example CIC-IDS2018, UNSW-NB15 or NSL-KDD), then load the results/comparison_table.csv that 07_Comparison.ipynb saves. It needs a Model column and an F1-Score column; the other metric columns are optional.
